# 第一阶段架构决策

## ADR-001：服务边界

固定为用户、积分、激励活动、发奖四个业务服务。兑换与抽奖均归入激励活动服务，避免共享活动、资格、奖品和库存时产生过度拆分。

## ADR-002：一致性模型

单服务内使用本地数据库事务；跨服务采用幂等业务号、Outbox、消息重试和人工补偿实现最终一致性。V0.1 不引入分布式事务框架。

## ADR-003：数据隔离

开发环境使用一个 MySQL 实例中的四个逻辑库；服务仍只允许持有自己的数据源凭据。完整隔离 Profile 在后续基础设施完善时添加。

## ADR-004：技术基线

后端基于 Java 21、Spring Boot 3.2.4、Spring Cloud 2023.0.1、Spring Cloud Alibaba 2023.0.1.0；前端基于 Vue 3、TypeScript 与 Vite。该组合匹配官方兼容表，版本由根 `pom.xml` 集中管理，升级须在兼容矩阵验证后进行。
